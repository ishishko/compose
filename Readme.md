# Proyecto de Automatización con Docker y Caddy

## Introducción
Odoo 1X CE configurado para que funcione FE ARCA con Reg. 5614/5614



## Instrucciones 


1. Clonar el repo

git clone -b 1X.0 https://github.com/devman-dev/docker_odooCE_ARCA_2025.git

2. Ejecutar up.sh

3. Se instala todo y levanta 

4. Luego para bajarlo, levantarlo o restartearlo es: 

- docker-compose up -d
- docker-compose down 
- docker-compose restar
